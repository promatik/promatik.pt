I love coding challenges, and I've done plenty of them on websites like hackerrank, codesignal and codecademy. The most exciting for me are code golf challenges, where you have to find a solution with the fewest bytes/characters possible.

One of these challenges was to create a BrainFck compiler. BrainFck is an esoteric coding language made of only 8 characters, ><+-.,[]. The language itself is crazy difficult, creating a compiler for it was even harder.
