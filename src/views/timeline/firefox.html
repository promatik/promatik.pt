Firefox 3.5 Mac OS theme was, for several months, one of the top 5 most-used Firefox themes in the world, with almost 2M downloads and 150k daily users. At the time, I didn't know how to code, so this theme was created, once again, mostly by trial and error.

I started to create the theme for myself because I liked customization, I used to create themes for my Nokia phones (I used paint to draw the images btw).

One day I decided to publish the theme, and boom, people started to use it, a lot, I even had a Chinese person asking me to create a special version of the theme with a bigger font size because of the Chinese characters.
